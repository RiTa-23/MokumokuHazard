# もくもくハザード
## 概要
### プロダクト概要
課題：北九州はスモーカーが多い→もくもく（副流煙）を避けたい！  
解決案：喫煙者・喫煙所・路上喫煙が多い地点を把握する  
開発するアプリ：喫煙者出没ハザードマップ

### メンバー
- リタ
- ひなQ
- レック

## 環境構築
1. リポジトリをクローン
```
git clone git@github.com/DIGIT-KITAQ-Flutter/MokumokuHazard.git
```
1. プロジェクトディレクトリに移動
```
cd mokumoku_hazard
```
2. パッケージのインストール
```
flutter pub get
```

## デバッグ
```
flutter run
```
